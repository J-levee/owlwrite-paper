# 排版：把论文排成可提交的 PDF 与 Word

> 本文件是排版能力的使用说明与对客话术。**能力是否开放以 `owl_meta` 的 `channels.typeset_ready` 为准**：
> 为 `false` 或字段缺失时，如实说「排版功能暂未对外开放」（服务级开关，不要说成「你的账号没开通」），不要报价、不要让用户白等。

## 一、它能做什么

两条路，用户手上有什么就走哪条：

| 用户手上有 | 走哪条 | 产出 |
|---|---|---|
| LaTeX 工程（.tex + 图片 + .bib，能自己编译的那种） | **工程直排** | PDF |
| 只有 Word 论文（.docx）+ 目标学校的模板文件（.docx） | **草稿按模板排版** | PDF + 同版式的 Word |

两条都能自动体检，但两种体检**不是一回事**（讲的时候别混）：

- **Word 稿按模板排**：模板就是标准，所以能逐项比「模板要求 vs PDF 实测」（8 项）。
- **LaTeX 工程直排**：模板是用户自己带的，我们没有"应该是什么"的答案，只报客观可测的 4 项：
  页数、字体是否全部嵌入、文字能否复制、有无内容超出纸面。**不要**说成"格式全部通过"。

## 二、LaTeX 工程直排：怎么让用户打包

一句话话术：「把整个工程文件夹压成 zip 发我就行，主文件叫 main.tex 最省事。」

打包要点（照这几条讲，用户一次就能成功）：

1. **主文件**命名 `main.tex` 最省事；放在某个文件夹里一起打包也行（如 `论文/main.tex`），会自动找到。
   只有工程里有**多个** `.tex` 时才需要指定 `entry`。
2. **图片**放在工程里，路径写成**相对路径**（`figures/fig1.png`）。
   写成 `C:/Users/xxx/Desktop/fig1.png` 这种本机路径会读不到——会被换成占位框，并在返回里提示改相对路径。
3. **参考文献**：`.bib` 一起打包；自定义的 `.cls` / `.sty` 也一起打包，**保持原有相对位置**。
4. **不要在意构建脚本**：`.latexmkrc`、`Makefile`、CI 配置、`.gitignore` 这类文件会被自动忽略，不影响出稿，也不会被执行。
5. 体积：单文件 ≤ 20MB，整包 ≤ 60MB，文件数 ≤ 800。

## 三、上限与例外（提前讲，别等失败）

**支持**：XeLaTeX + 中文排版（ctex）、GB/T 7714—2015/2025 参考文献样式（Word 模板排版可用
`refs_std` 切换）、盲审版（Word 模板排版可用 `blind` 开）、TeX Live 2026 里的常见宏包、
png/jpg/pdf 插图、`\input` / `\include` 多文件、表格与公式、目录 / 图表目录 / 附录 / 致谢。

**不支持**（直说，不要试）：

| 不支持 | 原因 | 怎么答用户 |
|---|---|---|
| `\write18`、`\input\|"cmd"` 之类执行系统命令 | 服务端一律禁止执行命令 | 「出于安全，稿件里不能执行系统命令；这类写法请本地跑」 |
| 需要联网抓数据的宏包（如 `minted` 联网、`\include{http…}`） | 服务端不联外网 | 「需要联网取数据的宏包用不了，请改成离线写法」 |
| `.eps` 图片直接插入 | XeLaTeX 不收 eps | 「eps 请先转成 pdf 或 png，我再排」 |
| Word 里的宏（.docm）、域代码、修订痕迹 | 只读正文结构与样式 | 「先把修订接受、宏去掉再发我」 |
| 加密 PDF、扫描件当正文 | 取不到文字 | 「扫描件排不了，请给可编辑的 docx 或 tex」 |

## 四、Word 草稿按模板排版：怎么讲

1. 要**两份文件**：自己的论文 `.docx` + 学校给的模板 `.docx`（模板就是学校那份「格式要求/范文」）。
2. 从模板里读：纸张与页边距、各级标题字体字号、正文字体字号行距、首行缩进。
3. 读不准的地方（模板本身不规范、同一项出现多种写法）**必须问用户，不要替用户猜**。
   一次只问真正有歧义的 3–5 条，别把整张规则表甩给用户逐条确认。
4. 出稿给 PDF + Word 两份，Word 版版式与 PDF 一致，方便用户继续改。

### 交付时必须讲的字体说明（2026-11-02 起，不许省略）

PDF 与 Word 用的不是同一套字体，**每次交付都要主动说明**，不能等用户发现：

- **PDF**：用开源等效字体渲染并嵌入（宋体→思源宋体、黑体→思源黑体、楷体→霞鹜文楷、
  仿宋→朱雀仿宋、西文→Tinos）。版式、字号、行距、缩进与模板一致，
  但字形与学校指定的商业字库有细微差异（笔画、字重、标点位置）。
- **Word**：按模板要求的字体名（宋体/黑体/楷体/仿宋/Times New Roman）设置，
  由用户本机渲染。用户电脑没装这些字体时，Word 会替换字形。
- **用户要绝对准确怎么办**：让用户下载 Word 版，在**自己的电脑上用 Word「另存为 PDF」**
  导出后提交。这是唯一能保证字体名与字形都对齐学校要求的路径，不要承诺 PDF 直出能做到。
- 不要说"PDF 里是宋体"——它不是。说"宋体等效字体"或"思源宋体（宋体等效）"。

接口返回里 `font_notice.text` / `font_notice.short` 就是给用户看的原文，直接引用，不要改写文字。

### 盲审版与参考文献标准（`blind` / `refs_std`，仅 Word 模板排版）

| 参数 | 什么时候开 | 效果 |
|---|---|---|
| `blind=true` | 用户说「盲审」「送盲审」「匿名评审」 | 封面作者/学号/导师脱敏为 `***`，致谢整节隐藏 |
| `refs_std="2025"` | 学校/期刊明确要求 GB/T 7714—2025（2026-07-01 起实施） | 参考文献按 2025 版重排：正式出版电子资源删「引用日期」、新增 PP/DS/CM/MM/A 等类型 |

- 两个参数**只对 `mode=docx` 生效**；LaTeX 工程的封面与参考文献样式由工程自带文件决定，
  传了会被网关直接拒（422），不要试。
- 不确定学校用哪版标准 → 用默认 2015，并如实说「如果你们学校要求 2025 版告诉我，重排一次」。
- 盲审版交付时必须说清两件事：**封面已脱敏、致谢已隐藏**；正式提交版要关掉 `blind`
  重排一次（72 小时内同一篇稿只收 1 积分工本）。
- 参考文献**解析不了或没有参考文献区**时会原样保留，不会瞎改——返回的 `doctor` 里
  能看到重排了多少条；解析失败的条数也要转告，不要说「全部按新标准排好了」。

## 五、出稿后：格式体检单怎么讲

体检单是「拿 PDF 实物去量」，不是「把我们自己的参数念一遍」。所以它只报**真正测过的项**：

**Word 稿按模板排（逐项比对，通常 8 项）**：
纸张尺寸、左/右页边距、正文中文字体、正文字号、首行缩进（有足够样本时）、一级/二级标题字号、内容越界。
通过的项打 ✓，不一致的打 ⚠ 并给出「期望 / 实测」两个数。

**LaTeX 工程直排（只报客观项，4 项）**：页数、字体嵌入、文字可复制、有无超出纸面。
这四项里「字体嵌入」最该主动说：字体没嵌入，评审电脑上打开就会变形——这是送审被打回的常见原因。

- **没测的项不显示通过**（行距、页眉页脚等暂未纳入）。用户问「行距对不对」时如实说
  「这项还没纳入自动体检，我可以人工看」。
- 模板里没看准的少数几项放在 `needs_confirm` 里：一次问完（"你们学校一级标题是黑体还是宋体？"），
  不要拿整张规则表让用户逐条确认。

讲法："8 项都对着模板量过，其中 7 项一致；二级标题字号实测 16pt、模板要求 14pt，差 2pt。"
不要只说「格式没问题」——那是空话，用户拿这句话交不了稿。

## 六、计费（不写死价格）

- 排版**按篇一口价**，按页数分档（期刊论文 / 学位论文常规 / 长篇 / 超长），**以 `owl_quote` 实时返回为准**；
  报价前先说「价格以实际报价为准」，并把积分折成钱讲给用户听（1 积分 = 0.01 元）。
- **报价即最终价**：不因实际页数与估算有点差别再补收——这点要主动说，用户最怕秋后算账。
- **72 小时内同一份稿（含同一模板）改格式重排只收 1 积分工本**——这条必须主动说，
  用户最怕「改一轮收一次钱」，而这正是学位论文的常态。
- 失败不计费；超时或服务异常没出稿，如实告知并说明「本次未产生费用」。

## 七、隐私与安全

- 原稿在临时目录里处理，**24 小时内清理**；成品 PDF / Word 保留 7 天供用户下载，到期自动删除。
  （用户问「会不会一直存着我的论文」→ 按这条答，不要说「出稿即删」，那是错的。）
- 不执行稿件里的任何命令；不联网；不读取工程以外的文件。
- 用户问「我的论文会不会泄露」→ 照上面三条答，不承诺额外的东西。

## 八、失败怎么讲（照这张表说，不要丢原始报错）

| 情况 | 返回的 `fail_class` / `error` | 对用户说什么 |
|---|---|---|
| 传的不是 zip | `bad_zip` / `bad_params` | 「这不是压缩包，把整个工程文件夹压成 zip 再发我」 |
| 压缩包里没有 .tex | `no_entry` / `bad_params` | 「包里没有 LaTeX 主文件，把 main.tex 一起打进去」 |
| 多个 .tex 分不清主文件 | `no_entry` / `bad_params` | 「包里有 N 个 .tex，请把主文件命名成 main.tex」 |
| Word 文件读不出来（加密/扫描件/扩展名不符） | `bad_params` | 「这个 Word 打不开，请用 Word 另存为 .docx 再试」 |
| 缺宏包 | `typeset_failed` | 「用到了本机没有的宏包 X，请换常见宏包或把 X.sty 一起打包」 |
| 缺文档类 / 参考文献库 | `typeset_failed` | 「X.cls（或 X.bib）没在包里，一起打包后重传」 |
| 编译超时 | `upstream_error` | 「稿件太大或编译卡住了，先按原样重试一次；确实超大要分章打包时先说清楚：**分开排会按篇分别计费**，确认后再做」 |
| 排队满 / 同一账号上一个还没排完 | `too_many_requests` | 「现在排队的人多，1 分钟后重试，不会重复扣费」 |
| 体积超限 | `file_too_large` | 「整包超过 60MB，先把图片压一压或分章打包」 |
| 服务维护中 | `ops_upstream_account` | 「排版服务正在维护，我先帮你记下，稍后再试」 |
| 功能未开放 | `typeset_disabled` | 「排版功能暂未对外开放」（服务级，不要说成账号没开通） |
| 文件不存在 / 不是本人的 / 已过期 | `bad_file` | 「这份文件我没拿到，重新发我一次（或重新上传）」 |
| 报价过期或已用过 | `quote_expired` / `quote_consumed` | 「报价超时了，我重新算一次，价格一样再确认」 |
| 报价与本次稿件不一致（换了文件或页数） | `quote_mismatch` | 「这次的文件和刚才报价的不是同一份，我重新报个价（本次未扣费）」 |
| 余额不足 | `insufficient_balance` | 「积分不够这一单，充值后我接着排（不会先扣一半）」 |
| 上传超时 / 服务不可用 | `upstream_error` / `typeset_unconfigured` | 「排版服务一时没响应，稍后再试；本次未扣费」 |

自动修过的项（补 `\end{document}`、换参考文献样式名、缺图占位、裸下划线转义、普通文档类补中文支持）
会在返回的 `doctor.fixes` 里列出，**要转告用户改了什么**，不要闷着不说。

## 九、边界

- 排版只做「把用户写好的内容按格式排出来」，**不改内容、不代写**。
- 不承诺「一定过格式审查」：学校模板本身有歧义时，以用户确认的规则为准。
- 遇到扫描件、加密文件、宏文档，直接说做不了，别反复试。
