# 覆盖维度表（coverage）

> 用途：缺口信号判定 `in_taxonomy` —— 用户问到表外场景时，Agent 应承认边界并按「下一步」处理，而不是硬编。

| 维度 | 已覆盖 | 明确不覆盖（会明确告知用户） |
|---|---|---|
| 任务类型 | 文献检索、论文写作、查重、AIGC 检测、格式检测、智评评级、图像/数据可信度、参考文献质量、校对、引文核验、撤稿把关、余额充值、产物落盘 | 在线协同编辑、投稿代投、翻译润色整篇、开题答辩 PPT 制作 |
| 身份场景 | 本科生、研究生、科研人员、期刊投稿人、职称评审、课程作业 | 企业年报/专利撰写、非学术写作 |
| 语言 | 中文（中文期刊库为主）、英文（全球库 + Crossref 兜底） | 小语种（日/德/法）系统性检索 |
| 检测品类 | 查重 6 版、AIGC 6 版、格式、智评 4 版、图像 2 版、文献质量、校对 | 专利查新、会议论文格式模板库 |
| 输入形态 | 纯文本全文（`content` 直传）、本机文件（`owl_upload` 换 `file_id`：docx/doc/pdf/txt，含原始图）、参考文献列表（GB/T 7714 等编号格式）、题目+大纲 | 扫描件 OCR、加密 PDF、超长（>10 万字）一次性检测 |
| 交付形态 | 对话内结论 + 本地目录落盘 + 报告下载链接 | 云端长期托管、多人共享空间 |
| 数据边界 | 撤稿库收录 8.6 万+ 篇（RISP 撤稿与关切库，每日更新），「无记录」只等于本库未收录 | 老文献/小出版社完整覆盖、PubPeer 全量评论抓取 |
| 学术诚信 | 检测（查重 / AIGC / 格式 / 智评）属合规自查 | 代写并代为提交违纪作业/论文 |
| 失败处理 | 6 类错误码分支、自动退款告知、限频退避 | 上游大面积故障时的补偿策略（需人工邮箱） |
| 商业化 | 报价确认、余额、充值、到账核对 | 发票开具、企业采购合同（转 vipsmart@vipslib.com） |

## 触发边界

- 用户问「能不能免费」→ 讲清计价，不承诺免费额度（当前注册赠送以实际到账为准）。
- 用户问「有没有全文 PDF」→ 中文期刊用 `owl_fulltext`（200 积分/篇，返回约 1 小时有效的官方直链）；外文先走 `owl_oa`（0 积分）；两者都不行才说明需机构权限，不虚构。
- 用户问「能不能帮我把论文改成原创通过查重」→ 不做（红线）。
