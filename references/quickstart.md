# 三步上手（不需要配置 MCP）

装好技能后，按下面三步即可在对话里直接使用。全程不需要编辑配置文件、不需要额外安装依赖。

## 第 1 步：注册，拿到你的 key

在对话里对助手说「我要注册夜猫子」，按提示给邮箱、报一次验证码即可。
注册成功会返回一串以 `owl_sk_` 开头的 key——**只显示一次**，先存到安全的地方。

已有账号（记得注册邮箱）就说「我登录一下」，走验证码登录，余额与历史记录都还在。

## 第 2 步：把 key 交给助手保存一次

把 key 粘进对话，助手会执行：

```
echo <你的 key> | python <技能目录>/scripts/owl.py init
```

init 会**先校验 key 再保存**（校验失败不落盘）；若本机已保存过其他账号的 key，需要加 `--force` 才会覆盖（防止误换账号）。

key 保存在本机 `~/.owl_creds.json`（仅本人可读），**不需要**粘到任何网页或配置文件里。
Windows 系统对文件权限支持有限，请勿在多人共用账号的电脑上保存 key。

## 第 3 步：自检

```
python <技能目录>/scripts/owl.py doctor
```

看到连通性、凭据、版本、余额都正常，就可以直接说「帮我找文献 / 写初稿 / 查重 / 排版」了。

## 常用命令（助手会自动用，你了解即可）

| 想做的事 | 命令 |
|---|---|
| 查余额 | `owl.py wallet` |
| 找文献 | `owl.py search "关键词"` |
| 写作（先报价再执行） | `owl.py quote --action write --params '{...}'` → `owl.py run --quote <id>` → `owl.py wait <run_id> --timeout 120`（没结束助手会自动再调一次，不要重复下单） |
| 查重 / AIGC 检测 | 先 `owl.py upload 论文.docx`，再按「查重」流程报价执行 |
| 排版 | `owl.py typeset 论文.docx --mode docx --template 学校模板.docx` |
| 充值 | 助手会生成一个本地支付页（含收款二维码），打开扫码即可 |

> 上表 JSON 示例用了单引号包 JSON：Windows cmd 下请改用 PowerShell 或把 JSON 写入临时文件。

## 常见问题

**没收到验证码？** 看垃圾邮件箱；15 分钟内有效，60 秒内不要重复发。

**提示凭据无效？** key 复制不完整（应以 `owl_sk_` 开头、共 50 位左右）；重新 `owl.py init` 一次即可。

**任务跑了很久没结果？** 正常现象：写作 3–5 分钟、查重 1–3 分钟。助手会分批查询进度，任务在服务端继续跑，**不要重复下单**。

**想换成支持 MCP 的客户端？** 也可以，两条路径能力完全一样，见 `mcp-setup.md`。
