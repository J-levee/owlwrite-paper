# standard vs guided 写作模式对照

> **同题实测（批 E，2026-10-29，生产真上游）**：8000 字同题《人工智能在医学影像诊断中的应用研究》——
> standard：实出 8744 字 / 约 4 分钟 / 实扣 5246 点（8744×600/1000 精确结算）/ 参考文献真实可溯；
> guided：两轮实测（20 分钟、40 分钟超时上限）均停在上游逐章确认未完成——**8000 字级长文 guided
> 全自动跑不完，guided 请控制在约 4000 字以内**，超长文用 standard。
> 本页决策口径与该实测一致；数字引用以上面实测为准，别凭记忆报。

## 决策表（对客展示用）

| | standard 标准模式 | guided 深度模式 |
|---|---|---|
| 生成方式 | 一次性连续写完整篇 | 逐章推进，章节间深度衔接 |
| 单价 | 600 点/千字（¥6/千字） | 约 1.5 倍（以 owl_quote 实时返回为准） |
| 耗时 | 较短（实测 8000 字约 4 分钟） | 明显更长（逐章多轮，实测 8000 字 40 分钟未完成） |
| 适合 | 课程论文、初稿、赶时间、先看结构再改 | 毕业论文定稿、期刊投稿、论证链复杂的中短文（≤4000 字） |
| 不适合 | 高标准定稿（结构深度不够） | 赶截止时间的急稿；超 4000 字的长文（实测跑不完） |

## 选择话术

1. 「默认**标准模式**，更快更便宜；要**深度模式**吗？逐章推进、质量更高，约 1.5 倍价。」
2. 用户说「随便/你定」→ 按用途推：作业/初稿 standard；毕业论文/投稿 guided，并说一句理由。
3. 用户要 guided 且字数 >4000 → 提醒：「深度模式逐章推进，超长文耗时可能非常久甚至超时失败，
   建议标准模式或分篇进行。」用户坚持则照做（超时风险已提前告知）。
4. 计费提醒必须带：「积分估算仅作参考，以实际扣除为准（按实际成文字数 × 所选模式单价结算）。」

## 常见追问

- 「能不能先用 standard 出稿再升级 guided？」→ 不能在原稿上「升级」；guided 是另一次任务，费用另计。
- 「哪个查重过更容易？」→ 查重结果取决于内容与引用规范，与模式无必然关系，不做承诺。
- 「差异到底在哪？」→ 讲决策表第 1 行的生成方式差异即可，不夸大（guided 不保证查重率/成绩）。
